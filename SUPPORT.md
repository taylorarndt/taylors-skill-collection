# Getting help

1. Read the [README](README.md). The "Before you start" section covers the
   usual install problems, such as `npx` not being found.
2. If the problem is with a skill by someone else, check that author's
   repository. The link is in the skill's entry.
3. Still stuck, or an install command on this page no longer works? Open an
   issue with the
   [Report a problem](https://github.com/taylorarndt/taylors-skill-collection/issues/new?template=report_a_problem.yml)
   form.

For security problems, see [SECURITY.md](SECURITY.md) instead of opening an
issue.
