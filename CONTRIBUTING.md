# Contributing

Thanks for wanting to help. This is a personal collection, so the process is
light.

## How the collection works

This is a list of skills I use, not a directory of every skill there is. A
skill gets added after I have tried it and kept using it. That is what keeps
the list honest: everything on the page is something I can vouch for.

## If you have a skill I should try

Open a
[Suggest a skill](https://github.com/taylorarndt/taylors-skill-collection/issues/new?template=suggest_a_skill.yml)
issue. Tell me what it is, where it lives, who made it, and what it is helpful
for. Suggesting your own skill is welcome.

I will try it. If it earns a place in my daily work, I add it to the page with
credit to the author and a link to their repository. If it does not fit how I
work, I will say so in the issue and close it. That is not a judgement on the
skill.

Please do not open a pull request that adds a skill to the list. Use the issue
so I can try it first.

## If something on the page is wrong

Skills move, and install commands change. If a link is broken or a command no
longer works, open a
[Report a problem](https://github.com/taylorarndt/taylors-skill-collection/issues/new?template=report_a_problem.yml)
issue, or send a pull request with the fix.

## Pull requests

Pull requests are welcome for:

- Fixing a broken link, an outdated install command, or a mistake
- Improving one of my own skills in the [skills](skills) folder

For anything larger than a small fix, open an issue first so we can agree on
the approach. Keep each pull request to one fix.

## Rules for the page

- Skills by other people are linked, never copied. The link goes to the
  author's own repository.
- Every entry says who made it, what it is helpful for, and how to install it.
- Install commands come from the author's own instructions, and you have run
  the ones you change.

## Accessibility

I am blind and use a screen reader. Everything in this repository must make
sense read aloud as plain text. Do not add emoji, decorative characters, or
images without real alt text. Headings carry the structure.

By contributing you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
